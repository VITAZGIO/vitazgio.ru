# ТЗ «Ретранслятора» по ступеням

Общая картина, архитектура и итог обсуждения — в `../phone-access-plan.md`.
Здесь тот же план, нарезанный на отдельные задания: одно задание = один
заход = один APK = одна приёмка хозяином.

| № | Файл | Что делает | Приёмка |
|---|---|---|---|
| 1 | `01-agent-stub.md` | Агент-заглушка, мост на сайте, сборка APK, статус «онлайн» | Пролежал ночь — утром онлайн |
| 2 | `02-webview-shell.md` | Оболочка-браузер: сайт живёт внутри приложения | Поделиться, скачать, выбрать файл, музыка в фоне |
| 3 | `03-screen.md` | Экран телефона на ПК | Видно экран, задержка < 1 с |
| 4 | `04-files.md` | Файлы телефона под готовой страницей `/files` | Фильм закинулся при выключенном экране |
| 5 | `05-touch.md` | (по желанию) управление пальцем с ПК | Тап и свайп доходят |
| 6 | `06-audio.md` | (по желанию) звук телефона | Слышно звук вместе с картинкой |

Порядок: 1 → (2 параллельно ночному тесту) → 3 → 4. Ступени не смешивать:
при поломке иначе непонятно, что виновато.
