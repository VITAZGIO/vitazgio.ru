# ТЗ 5 (по желанию). Управление пальцем с ПК

Делать только если хозяин захочет после ТЗ 3 и ТЗ 4. Смотреть экран уже
можно; здесь добавляется возможность в него **тыкать** мышкой с ПК.

## Что сделать в приложении

- `AccessibilityService` *(служба спец-возможностей: системный механизм,
  которым Android позволяет приложению нажимать за человека)* и
  `dispatchGesture` — тапы, долгие нажатия, свайпы.
- Координаты приходят от страницы `/phone` в долях от ширины и высоты
  (0…1), а не в пикселях: у ПК и телефона разные разрешения, а телефон
  ещё и поворачивается.
- Отдельно кнопки «Назад», «Домой», «Недавние» — это не жесты, а
  `performGlobalAction`.

## Что сделать на сайте

- На `/phone` — приём мыши и клавиатуры поверх `canvas`, отправка в сокет.
- Тумблер «управление» рядом с картинкой: по умолчанию **выключено**, чтобы
  случайный клик по экрану ничего не нажал на телефоне.

## Протокол

```
сайт → агент  {"type":"tap","x":0.51,"y":0.32}
сайт → агент  {"type":"swipe","x1":0.5,"y1":0.8,"x2":0.5,"y2":0.2,"ms":180}
сайт → агент  {"type":"key","name":"back"}
```

## Ловушка, о которой надо знать заранее

На Android 13+ у приложений, поставленных файлом (а не из магазина),
спец-возможности спрятаны за «разрешить ограниченные настройки»:
Настройки → Приложения → Vitaz Gio → три точки → разрешить. Делается
руками один раз, но без этого пункт в списке спец-возможностей будет
серым, и это не поломка приложения.

## Приёмка

Тап по экрану на ПК открывает то, по чему тыкнул; свайп листает; кнопка
«Назад» работает. Тумблер выключен — клики ничего не делают.
