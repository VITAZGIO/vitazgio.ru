# diy.py — DIY /diy

**Назначение:** личная галерея проектов (заметки + вложения + обложка),
листается одной раскладкой.

**Точки входа:** `/diy`, `/diy/a/<item_id>`, `/diy/asset/<item_id>/<path:name>`,
`/diy/cover/<item_id>`, API `/api/diy` (GET/POST), `/api/diy/<item_id>`
(DELETE), `/api/diy/<item_id>/asset` (POST/DELETE), `/api/diy/<item_id>/cover`
(POST/DELETE).

**Данные:** элементы и файлы — как в остальных JSON-хранилищах сайта, рядом
с кодом; вложения/обложки на диске, отдаются по `item_id`+имени.

**Инвариант (нельзя ломать):** раскладка ровно одна — **Кладка**
(JS-masonry, класс сетки всегда `m-mosaic`, НЕ CSS `column-count`).
Переключателя видов больше нет — хозяин попросил оставить только Кладку;
не возвращать Сетку/Барабан/Веер/Соты.

**Тест перед правкой:** `scratchpad/diy.js` (переключателя нет, класс
всегда `m-mosaic`, кладка не ломается при смене полки).
