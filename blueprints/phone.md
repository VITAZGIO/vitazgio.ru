# phone.py — телефонный агент и «ретранслятор» (android/ + desktop-браузер)

Приложение — оболочка-браузер вокруг сайта (WebView на `/cabinet`) плюс
фоновая служба, которая держит связь с сервером. ТЗ по ступеням —
`docs/phone-access-plan.md`, следующие ступени — `docs/phone-tz/`.

**Точки входа:** `/phone` (экран+звук+управление), WebSocket `/ws/agent`
(вход телефона) и `/ws/phone` (вход зрителя-браузера), `/api/phone/agent`,
`/api/phone/token`, `/api/phone/tokens`(+`/<id>` DELETE), `/app`,
`/api/app/version`, `POST /api/app/pull`.

## Ступень 1 — сам агент (`/ws/agent`)

Телефон сам приходит вебсокетом и держит его открытым (входящих быть не
может — CGNAT у оператора). Первое сообщение — `hello` с
`PHONE_AGENT_TOKEN` из `.env`, не тот токен — сокет закрывается. Реестр
живых агентов — словарь в памяти процесса; молчит дольше минуты — дворник
выкидывает. Сервер шлёт `ping` раз в 25 сек, агент отвечает `pong`.

**Статус MOBILA на `/netbird` — из этого реестра, не из ICMP-пинга**
(`_phone_publish_status` в `app.py`, телефон изъят из пинг-цикла через
`PING_SKIP_IPS` — ICMP до него никогда не дойдёт). `vnc_enabled` снят: VNC
туда не работает.

## Ступень 2 — оболочка-браузер (android/)

`MainActivity` — WebView на весь экран, старт на `/cabinet`. Нативной
разметки один кусок — заглушка «нет связи». Всё остальное рисует сайт —
правки приезжают обычным деплоем, без пересборки APK.

**Токен не вбивают руками:** хозяин входит в кабинет внутри оболочки →
`cabinet.html` видит `window.VGPhone` → `/api/phone/token` → мост кладёт
токен в `EncryptedSharedPreferences`. На диске сервера только хэши
(`data/phone_tokens.json`), отзыв поштучный — панель на `/apps`. Общий
`PHONE_AGENT_TOKEN` — запасной путь.

**Мост `WebBridge.kt` узкий намеренно:** два метода (`getStatus`,
`saveToken`), происхождение проверяется на КАЖДОМ вызове (адрес кадра в
`volatile`-поле). На сайте есть страницы с текстом извне (ответы нейронки,
имена файлов) — мост не «сделай, что скажут».

Ловушки WebView (не Chrome) уже закрыты — таблица и детали:
`android/README.md` (Share/выбор файлов/скачивание/назад/сессия/разрешения/
второе окно плеера).

**Самообновление:** сверяет `versionCode` с `/api/app/version`, ставит
через `REQUEST_INSTALL_PACKAGES`. `POST /api/app/pull` тянет APK из
последнего релиза на VPS (общего диска с раннером нет), `/app` отдаёт его
за `login_required`, `/api/app/version` пускает по сессии ИЛИ
`X-Agent-Token`. Версия — число в имени файла (`vg-agent-7.apk`).

**Подпись APK:** `.github/workflows/android.yml` кэширует
`~/.android/debug.keystore` через `actions/cache` (ключ
`android-debug-keystore-v1`) — иначе каждая сборка новым случайным ключом
= Android считает разной подписью, обновление требует снести старое.
Кэш виден только на своей ветке; веткам `claude/**` неоткуда его взять,
если не сохранён на `main` — заводится там вручную через
`workflow_dispatch`, если однажды обновление снова попросит удалить
старое приложение (кэш GitHub чистит через 7 дней простоя).

**Служба:** foreground-служба типа `specialUse` (НЕ `dataSync` — у того в
Android 15 лимит ~6ч/сутки). **Ловушка, ронявшая приложение:** манифест
объявляет типы `specialUse|mediaProjection|microphone` разом —
`startForeground()` без явного типа применяет ВСЕ разом, а Android 14 не
даст ни разрешения на запись, ни согласия на захват при обычном запуске →
`SecurityException` → падение при входе в кабинет. Все вызовы — через
`goForeground(типы)`, объявляющий только то, что сейчас оправдано; экран и
звук добавляют свои типы в момент старта. Падения пишутся в журнал + файл,
оболочка показывает карточкой при следующем запуске.

## Ступень 3 — экран (`/ws/phone` ← мост ← `/ws/agent`)

Тот же приём, что у guacamole: оба соединения исходящие, сервер только
перекладывает байты. Кадры — двоичные: тип (1=SPS/PPS, 2=опорный,
3=разностный) + метка времени мкс (8 байт BE) + H.264 Annex-B. Зритель —
WebCodecs (`VideoDecoder`), строку кодека достаёт из самих SPS.
`description` декодеру **не передаётся намеренно** — WebCodecs ждёт AVCC
только когда он задан, а MediaCodec отдаёт Annex-B.

Сервер помнит последние SPS/PPS (зритель посреди трансляции обязан
получить их первым) и очередь на каждого зрителя (переполнилась — чистим и
просим опорный кадр). Зрителей не осталось → телефону `screen-pause`,
`setSurface(null)` — **захват не выключается совсем**: Android 14 спрашивает
согласие на каждую НОВУЮ сессию, полная остановка означала бы новый
системный запрос. Поворот телефона — `resize`+`setSurface`, не второй
`createVirtualDisplay` (запрещён на одной сессии).

Гейт: `login_required` + суточный пароль консоли. Экран не включится без
подтверждения на телефоне — если он не в руках, служба кладёт уведомление,
запустить окно из фона Android не даёт. Код — `android/.../ScreenCaster.kt`,
протокол `screen-start/stop/pause/resume/key` — неизвестный тип обе стороны
игнорируют, не падают.

## Ступень 6 — звук

Тот же захват (`AudioPlaybackCaptureConfiguration`), AAC 44,1кГц моно.
**Свой тип сообщений и своя метка времени** (5=параметры, 6=звук) — не
мешать с видеокадрами, рассинхрон лечится сдвигом звука в браузере
(`audioShift`). Экран выключили — звук гаснет сам. На странице звук **по
умолчанию выключен**. Ограничение Android, не баг: захватывается звук
только приложений без `ALLOW_CAPTURE_BY_NONE` (ютуб/музыка — без звука).

## Ступень 5 — управление пальцем

Тумблер «управление» на `/phone`, **по умолчанию выключен**. Координаты —
долями (0…1), не пикселями. Кнопки Назад/Домой/Недавние —
`performGlobalAction`, не жесты. На телефоне — `TouchService` (служба
спец-возможностей). Ловушка Android 13+: у приложений из файла спец-
возможности спрятаны за «разрешить ограниченные настройки»; на HiOS ещё и
сам пункт не появится в списке, пока это не сделано первым шагом.

Свайп/выделение различаются по `heldBeforeMove` в `templates/phone.html`
(протокол `ms`/`ms2` в `{"type":"touch","action":"select"}`, требует API 26+
`continueStroke`). **Баг с пробелом (чинен):** `keydown`-обработчик слал
символ без `event.preventDefault()` — пробел мог активировать сфокусированную
кнопку САЙТА вместо печати на телефоне; правка — `preventDefault()` на
каждый символ + снятие фокуса при включении управления.

Служба не включена — телефон честно отвечает отказом.

**Полный экран `/phone`:** fullscreen у `#stage` целиком (Fullscreen API
рисует только то, что внутри). На узких/тач-экранах — колонка `#navCol`
(Назад/Домой/Недавние) вместо панели `#keys`, видна только при
управление+мобильный fullscreen разом. Класс ставит `fullscreenchange`, не
клик по кнопке.
