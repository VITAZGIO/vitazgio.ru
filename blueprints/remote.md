# remote.py — кабинет, NetBird, консоль/RDP/VNC

**Точки входа:** `/cabinet`, `/netbird`, `/notifications`+API, WebSocket
`/ws/console/<ip>`, `/ws/claude`, `/ws/rdp/<ip>`, `/ws/vnc/<ip>`, плюс
`/api/netbird/status`, `/api/console/login`, `/api/pc/shutdown`, `/api/wol`.

## Вкладка Claude (`/ws/claude`)

Готова как ЗАГОТОВКА (коммит 3a20c01). Браузер → WebSocket `/ws/claude` →
SSH (paramiko) → tmux → команда — тот же канал, что у консоли кабинета.
Вкладки на странице = сессии tmux (`vg-1`, `vg-2`…), переживают закрытый
браузер. Гейт: пароль кабинета + суточный пароль консоли. **В коде НЕТ
ничего специфичного для Claude** — запускает то, что указано в
`CLAUDE_BIN`, туда встанет любой консольный агент. Страница/API
`/claude`, `/api/claude/state` живут в `blueprints/ai.py` (тонкая обёртка,
см. `ai.md`) — здесь только канал.

Пока `CLAUDE_HOST` не задан в `.env` — страница висит безвредной
заглушкой. Настройка: `CLAUDE_HOST`, `CLAUDE_DIR`, `CLAUDE_BIN`.
Не доделано: автоподхват после «отцепиться», прикрепление фото, вход по
ключу.

## SFTP — кнопка «Файлы» в оверлее RDP/консоли

При отправке формы RDP или SSH логина (`netbird.html`) в фоне летит
`POST /api/files/connect` с теми же логином/паролем (`quickSftpConnect`,
список машин — `{{SFTP_IPS}}` отсюда). Реализация самого файлового
менеджера и соединения — в `blueprints/files.py`, см. `files.md`.

## Полный экран — RDP-оверлей

Кнопка ⛶ рядом с «Закрыть» в `.rdp-header-actions`, fullscreen у
`#rdp-overlay` целиком (заголовок + картинка + тулбар разом — оверлей и
так `position:fixed;inset:0`, Fullscreen API поверх него ещё и прячет
адресную строку браузера). `closeRdp()` сама выходит из fullscreen, если
он активен, — иначе закрытие RDP оставляло бы браузер зависшим в
fullscreen с пустым чёрным оверлеем. (Аналогичная кнопка на `/phone` —
своя, описана в `phone.md`.)

**Инвариант:** гейт консоли/RDP/VNC/файлов — один и тот же суточный
пароль (`console_authenticated`), не заводить второй механизм входа.

**Тест перед правкой:** живая проверка руками (консоль/RDP/VNC вебсокетами
автотестами не покрыты) — открыть `/cabinet` → `/netbird`, подключиться.
