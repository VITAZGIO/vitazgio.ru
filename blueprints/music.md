# music.py — фонотека /music + плеер (виджет и `/player/pop`)

**Точки входа:** `/music`, API `/api/music` (GET/POST), `/api/music/<id>`
(DELETE), `/api/music/folder` (POST/DELETE), `/api/music/op`,
`/api/music/file/<track_id>`, `/api/player/tracks`, `/vg-player.js`,
`/player/pop`.

## Избранная папка (звезда)

Любую папку можно пометить звездой (кнопка на плитке, только у хозяина) —
избранная **одна на всю фонотеку** (новая гасит старую при `fav:true` в
`music_folder_patch_api`). Даёт: (1) `/music` при первом открытии сразу
заходит в неё, а не в пустой корень; (2) `/api/player/tracks` и мини-плеер
кабинета играют **только** её содержимое с подпапками. Нет избранной — вся
фонотека. Флаг `fav` — в `music_folders[id]`, отдаётся в `/api/music`
(`fav_folder`+`fav` у каждой папки). Корневая крошка — «Вся музыка».

## Плеер (виджет + `/player/pop`)

Один `<audio>` на весь сайт: состояние едет между страницами через
`localStorage`, между вкладками — через `BroadcastChannel("vgplayer")`.

**Инварианты (нельзя ломать):**
- В памяти живёт **намерение** (`wantPlay`), не факт `!audio.paused` —
  иначе быстрое листание вкладок обрывает музыку. Снимается только
  настоящей паузой; служебные паузы помечены `quiet`.
- Перед автовключением `resume()` спрашивает через `BroadcastChannel`
  (ping/pong ~220мс), не играет ли уже другая вкладка.
- Кнопки «вынести в окно» (`VGP.popOut()`) открывают независимое окно
  `/player/pop` со своим звуком; эстафета ставит `audio.pause()` на сайте
  и сразу пишет `playing:true` в `localStorage` для нового окна — событие
  `pause` на время передачи помечено `quiet`, иначе затёрло бы `playing`.
- Внутри `/player/pop` — плавающее окно поверх всех (`floatOnTop`):
  Chrome/Edge через Document Picture-in-Picture, Firefox — видео-PiP
  (`captureStream()` → немой `<video>`, кликабельного списка треков там
  нет — железное ограничение). Класс `vgp-top` = «уже поверх», прячет
  кнопку повторно.
- Список треков в окне (`drawRows`) двухуровневый (папки → треки), выбор
  папки — из ПОЛНОГО дерева фонотеки (`/api/player/tracks?folder=<id>`
  или `__all__`), не только из загруженной очереди.
- `/vg-player.js` отдаётся `private, no-cache` + ETag по md5 текста —
  после деплоя браузер обязан перепроверить версию.
- Свои карточки подтверждений (`uiConfirm`/`uiToast`), не системные диалоги.

**Тесты:** `scratchpad/popfolders.js`, `popfold.js`, `player.js`, `flip.js`,
`popbtn.js`, `lag.js`.
