# login_log.py — журнал входов (/login-log)

**Назначение:** вкладка кабинета «Журнал входов» — кто и откуда заходил.
Самый маленький blueprint проекта (33 строки), на нём обкатывали паттерн
прямых импортов в задаче 34.

**Точки входа:** `/login-log` (страница), `GET /api/login-log` (данные).

**Где данные:** сам журнал ведёт **`core/auth.py`** (`log_login`,
пишется при каждом входе, включая автовход по доверенному устройству) —
здесь только показ.

**Гейт:** `login_required`.

**Эталон паттерна:** файл ничего не принимает аргументами — всё нужное
(`template`, `login_required`, `login_log`) берёт прямым импортом из
`core.auth`/`core.templates`, `ICON_LINKS` — из `blueprints.pwa`.
Регистрация в `app.py`: `create_login_log_blueprint()` без аргументов.
Новую фичу делать по этому образцу.

**Тест перед правкой:** `pytest tests/test_login_log.py -q`.
