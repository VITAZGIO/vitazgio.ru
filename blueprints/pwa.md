# pwa.py — установка сайта приложением, иконки, «Поделиться»

**Назначение:** делает сайт устанавливаемым (PWA) и принимает системное
«Поделиться» с телефона. Здесь же живут все иконки приложения.

**Точки входа:** `/manifest.webmanifest`, `/sw.js`, `/favicon.ico`,
`/icon-<size>.png`, `/icon-maskable-<size>.png`, `POST /share-target`.

**Где данные:** готовые png в `static/icons/` (`ICON_DIR`), шаблон
service worker — `templates/service_worker.js.tpl`. Своего состояния нет.

**Инварианты:**
- **`ICON_VERSION` поднимать при смене рисунка** — версия попадает в
  адреса иконок; браузер кэширует их по ссылке и на смену самой картинки
  не смотрит, старый значок останется висеть;
- маскируемый значок — ОТДЕЛЬНЫЙ файл с запасом по краям: Android режет
  иконку в круг и обкусал бы углы у обычной;
- `ICON_LINKS` отсюда импортируют почти все страницы — менять формат
  строки, не проверив остальные blueprints, нельзя;
- стратегия service worker намеренно «сначала сеть»: из кэша берётся
  только офлайн-страница, иначе правки не были бы видны без переустановки;
- `/share-target` — запасной путь, когда обработчик в браузере ещё не
  встал; файл падает в особую папку Download дропа (см. `drop.md`),
  текст без файла сохраняется заметкой `.txt`.

**Тест перед правкой:** `pytest tests/test_pwa.py -q`.
