# drop.py — дроп (личное облако) /drop

**Точки входа:** `/drop`, `/d/<token>`(+`/raw`,`/save`), API
`/api/drop/list`, `/api/drop/upload/*`, `/api/drop/op`, `/api/drop/op/<job_id>`,
`/api/drop/folder`, `/api/drop/share/<item_id>`, `/api/drop/trash*`,
`/api/drop/text/<item_id>`, `/api/drop/zip/<item_id>`, `/api/drop/download/<item_id>`,
`/api/drop/qr`.

## Совпадение имён при загрузке (как в проводнике)

Файл с уже занятым в этой папке именем спрашивает карточкой (`askConflict`):
**Сохранить оба** (дописывает `(2)`, `freeName`), **Заменить** (старое в
корзину через `/api/drop/op` op=delete, новое встаёт под тем же именем),
**Пропустить**. Галочка «Применить ко всем» (`forAll`) запоминает выбор на
остаток пачки. Тест — `scratchpad/dropconflict.js`.

## Особая папка MUSIK

Не хранит своё — показывает саму фонотеку (папки `mf_`, треки `mt_`).
При `parent == "musik"` или `parent` с префиксом `mf_` создаётся НАСТОЯЩАЯ
папка фонотеки (`music_folders`, id уже `mf_`), с проверкой глубины
`MUSIC_MAX_DEPTH`. Загрузка роутится в фонотеку (`_drop_music_take`).

## Особая папка Download

Второй `special`-корень (`DROP_DOWNLOAD_ID = "download"`, заводится сам
`_drop_ensure_download()`), в отличие от MUSIK ничего не подменяет — обычная
папка дропа с фиксированным именем/иконкой, без переименования и без
удаления из корзины (`if item.get("special"): return` в `_drop_trash`).
Сюда по умолчанию падает: «Поделиться» с телефона (без явного выбора папки
спросить некого) и кнопка **VG** со страницы SFTP-файлов (`/files/<ip>`,
перенос напрямую с машины в дроп — реализация и её инварианты в
`files.md`). Обычная загрузка через `+`/drag-n-drop идёт в открытую папку.

**Инвариант, который уже один раз сломался:** подмена веса для MUSIK
(«весит как фонотека, а не как дерево дропа») должна проверять конкретно
`drop_musik_id`, не общий флаг `v.get("special")` — иначе Download
показывал бы объём фонотеки вместо своих файлов. Сторожит
`test_download_folder_weight_reflects_its_own_files_not_music`.

**Тесты:** `tests/test_drop.py` (доступ + целость файла побайтово),
`scratchpad/dropconflict.js`. Пароль корзины — хэш sha256, не открытый
текст.
