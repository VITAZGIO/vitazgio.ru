# vitazgio.ru — память проекта

Личный сайт Виталия (VITAZGIO). Один файл `app.py` (~15 тыс. строк) на Flask,
HTML/CSS/JS живут строками прямо в нём. Деплой: пуш в ветку `claude/**` →
GitHub Action «Claude auto-merge» → main → «Deploy» (домашний раннер по SSH
через NetBird на VPS в Амстердаме, `docker compose up -d --build web`).

Ветка разработки: `claude/project-overview-2mnq1j`.

## Как проверять (важно)

- Питон: `python3 -c "import ast; ast.parse(open('app.py').read())"`.
- Встроенный JS: `scratchpad/jscheck.py` — вытаскивает скрипты со всех
  страниц и гоняет `node --check`. **Обязательно** после правок шаблонов.
- Ловушка: `\n` внутри питоновской строки `"""..."""` становится настоящим
  переносом и рвёт JS. В шаблонах писать `\\n`. Дважды из-за этого падал дроп.
- Живая проверка: Playwright + Chromium
  `/opt/pw-browsers/chromium-1194/chrome-linux/chrome`,
  `NODE_PATH=/opt/node22/lib/node_modules`. Локальный запуск —
  `scratchpad/run.sh` (пароль кабинета `testpass`).

## Что сейчас в работе / решено

### Вкладка Claude (кабинет → /claude)
Готова как ЗАГОТОВКА, залита (коммит 3a20c01). Разговор с консольным
помощником через сайт: браузер → WebSocket `/ws/claude` → SSH (paramiko) →
tmux → команда. Тот же канал, что у консоли кабинета. Вкладки = сессии tmux
(`vg-1`, `vg-2`…), переживают закрытый браузер. Пускает пароль кабинета +
суточный пароль консоли. В коде НЕТ ничего специфичного для Claude —
запускает то, что в `CLAUDE_BIN`, так что туда встанет любой консольный агент.
Пока `CLAUDE_HOST` не задан в .env — страница висит безвредной заглушкой.
Настройка: `CLAUDE_HOST` (машина из NetBird с SSH), `CLAUDE_DIR`, `CLAUDE_BIN`.
Не доделано: автоподхват после «отцепиться», прикрепление фото, вход по ключу.

### Плеер /vg-player.js — единый звук на сайт — правки
Виджет один на весь сайт (звук общий, `<audio>` живёт в модуле, а не в
странице), едет между страницами через `localStorage`, между вкладками
синхронизируется через `BroadcastChannel("vgplayer")`.
- **Баг «стопается при переключении вкладок»**: `resume()` на каждой новой
  странице/вкладке безусловно запускал `audio.play()`, если в
  `localStorage` было `playing:true` — а это правда, когда музыка играет
  в УЖЕ ОТКРЫТОЙ другой вкладке. Новая вкладка начинала параллельный
  голос, тот бродкастил `"play"`, и по правилу «одна вкладка играет,
  остальные молчат» ИСХОДНАЯ вкладка сама себя ставила на паузу — то
  есть просто открыть сайт во второй вкладке обрывало музыку в первой.
  Исправлено: перед автовключением `resume()` спрашивает через
  `BroadcastChannel` («ping») — не играет ли уже кто-то — и ждёт «pong»
  ~220мс; если ответили, эта вкладка не лезет со своим звуком.
- **Уровень громкости** — ползунок `data-volbar` в теле виджета (было
  только перемотка трека, без громкости); мьют — клик по значку
  громкости, помнит прошлый уровень. Использует уже существовавший
  `api.volume()`.
- **Плавающее окно поверх экрана** — кнопка `data-pip` (только если
  браузер умеет `documentPictureInPicture`, иначе кнопки просто нет):
  переносит DOM самого виджета в настоящее OS-level окно без рамок,
  поверх всех окон — тот же JS-контекст, тот же `<audio>`, звук не
  прерывается при переезде. Управляется и из окна, и с сайта (это в
  буквальном смысле один и тот же виджет, просто временно в другом
  document). Кнопка `data-remove` (крестик, видна только в этом режиме)
  убирает плеер насовсем — перетащить в корзину, как на странице, тут
  негде. Закрыл окно руками — виджет сам возвращается на страницу
  (`pagehide` на `pipWin`).
- Тест `scratchpad/player.js`: громкость кликом по ползунку, мьют/анмьют,
  два таба одновременно (второй не ворует звук у первого), открытие PiP,
  видимость контролов и работоспособность внутри него, возврат на
  страницу после закрытия. `/vg-player.js` теперь входит в
  `scratchpad/jscheck.py` отдельным пунктом — раньше как внешний скрипт
  (`<script src=...>`) вообще не проверялся.

### Страница «Нейронки» /neuro + /ai — чаты через OpenRouter — СДЕЛАНО
DeepSeek у OpenRouter в 2026 сняли с бесплатных моделей целиком, поэтому
перешли на другие. Одна карточка «Нейронки» в кабинете (нейтральный
акцент #9aa3c9, без фиолетового — раньше иконка карточки и градиент
MiniMax были случайно фиолетовыми, хотя цвета сети розовый/зелёный/
оранжевый; поправлено). `/neuro` — обёртка с тремя вкладками сверху,
каждая показывает `/ai?m=<модель>` в своём iframe и красится в свой цвет:
**MiniMax** (`minimax/minimax-m3:free`, розовый `#ff3d9a`/`#ff8fc4`,
multimodal — умеет фото), **NVIDIA** (`nvidia/nemotron-3-ultra-550b-a55b:free`,
зелёный `#76c900`/`#39ff14`), **Claude** (оранжевый `#d97757`/`#f0a184`).
Модель у каждой вкладки зашита в самой странице (`/neuro`), в `.env` она
не нужна — только `OPENROUTER_KEY`. Если модель вкладки ответила ошибкой
(сняли/переименовали/упёрлись в лимит), сервер сам перебирает список
живых бесплатных (раз в 15 мин подтягивает каталог `/api/v1/models`,
берёт всё с ценой 0).

Функционал чата на /ai:
- Список прошлых чатов слева, **папки** (создать/переименовать/удалить —
  удаление папки не трогает чаты, просто выкладывает их обратно),
  **переименование чата** (карандаш на строке), **перенос между папками**
  (иконка-папка на строке → меню), **закрепление** (булавка → своя секция
  «Закреплённые» сверху списка), **поиск по чатам** (фильтр по заголовку,
  крестик очищает). Сайдбар шире прежнего (317px, было 264) и **сворачивается**
  — кнопка внутри самого сайдбара (не в общей шапке справа, где она была
  нелогично оторвана от списка, который слева), а разворачивается назад
  плавающей кнопкой у левого края поверх чата (видна только когда список
  свёрнут — сам сайдбар в этот момент `width:0`, до кнопки внутри него не
  дотянуться). Состояние в `localStorage.aiSidebarCollapsed`.
- Подтверждения/ввод — **свои карточки** (`uiConfirm`/`uiPrompt`/`uiToast`),
  не системные `confirm()`/`prompt()`/`alert()` браузера: удаление чата и
  папки, создание папки, «В блокнот», предупреждение про большой PDF —
  всё в теме страницы (тёмная карточка, акцент текущей сети). Раньше
  системные диалоги торчали чужеродным окном браузера.
- На каждом сообщении (и своём, и ответе) — **кнопка «Копировать»**,
  на ответах ещё **«В блокнот»** (спрашивает название, переносит текст
  ответа в заметку через уже существующий `/api/notebook/entry`) и, на
  самом последнем ответе, **«Заново»** (перегенерировать — стирает
  последний ответ и просит модель заново тем же вопросом/фото/PDF,
  `POST /api/ai/chat/<id>/regenerate`).
- **Кнопка Стоп**: та же кнопка отправки, во время генерации превращается
  в квадрат-стоп (`AbortController` на fetch); то, что успело прийти,
  остаётся в чате и сохраняется — сервер ловит обрыв соединения как
  `GeneratorExit` в `finally` у `_ai_run_stream` и досохраняет частичный
  ответ, так что «Стоп» не роняет историю.
- Автозаголовок чата (`_ai_smart_title`) теперь долетает до сайдбара сразу
  первым кадром SSE-потока (`{"title": ...}`), а не только после
  перезагрузки страницы — иначе поиск по свежесозданному чату не находил
  его, пока заголовок ещё был «Новый чат» только на сервере.
- **Аватарка бота — по модели, которая РЕАЛЬНО ответила на конкретное
  сообщение** (`m.model`, хранится в `data/aichat.json` на каждой
  ответной реплике), а не по вкладке, из которой сейчас открыт чат —
  раньше переключение вкладок MiniMax/NVIDIA/Claude меняло буквы на
  аватарках у СТАРЫХ сообщений, хотя отвечали они на самом деле разными
  моделями. Функция `avaFor(model)` на фронте вместо старой глобальной
  константы `AVA`.
- Ответ потоком (SSE) с живой печатью + markdown (жирный, код, ссылки).
- Фото: браузер ужимает картинку, сервер шлёт vision-модели (для
  MiniMax уже сама умеет) и хранит в `data/aichat_img/`.
- **PDF**: отдельная кнопка-скрепка рядом с фото, до 8 МБ; текст
  вытаскивается на сервере через `pypdf` (`_ai_pdf_extract`, до 6000
  символов) и подкладывается в контекст на КАЖДОМ следующем ходе
  разговора (не только в момент прикрепления) — так что «а что там про
  X» на следующей реплике всё ещё видит документ. В чате — маленький
  значок с именем файла и на прикреплённом сообщении, и в композере
  перед отправкой.
- **Размышления (reasoning)** — у MiniMax и NVIDIA/Nemotron (проверка
  `_ai_wants_reasoning` по id модели) в запрос добавляется
  `"reasoning": {"enabled": true}`; поток размышлений приходит отдельным
  полем `delta.reasoning`/`delta.reasoning_content` (не смешивается с
  `delta.content`). Пока модель думает — над ответом раскрытый блок с
  текстом размышлений и тикающим таймером («Думает… N с»); на первом
  куске самого ответа блок сам сворачивается, подпись меняется на
  «Думал», таймер замирает на финальном числе — по клику на заголовок
  разворачивается обратно. Время до первого куска ответа считает сервер
  (`think_secs` в `_ai_run_stream`) и сохраняет вместе с текстом
  размышлений в сообщении (`reasoning`/`reasoning_secs` в
  `data/aichat.json`), отдаёт через `ai_chat_get` — при открытии чата
  заново блок так же на месте (свёрнут, с тем же временем). Кнопка
  «Копировать» на ответе размышления в буфер не тянет — берёт только
  `out.dataset.raw`, куда пишутся исключительно куски `delta.content`.
- Реплика юзера сохраняется СРАЗУ: лимит исчерпан — написанное не пропадёт.
- **Баг с остаточным фиолетовым/синим** (аватарка бота, пузырь своих
  сообщений, кнопка отправки, «Новый чат», скроллбары, ховеры) — чинили
  цвет вкладок раньше, но добрая половина мелких элементов на /ai
  по-прежнему была на хардкоженных `rgba(77,107,254,*)`/`rgba(139,123,255,*)`
  (старые синий/фиолетовый DeepSeek-цвета), а не на `var(--ac)`/`var(--ac2)`
  текущей сети. Заменено на `color-mix(in srgb, var(--ac) N%, transparent)` —
  этот же паттерн уже был в ходу на других страницах сайта.

Настройка на сервере (.env): только `OPENROUTER_KEY` обязателен.
`OPENROUTER_MODEL`/`OPENROUTER_VISION_MODEL`/`OPENROUTER_URL` — опционально.
Код: блок `# Нейросеть: чат с DeepSeek через OpenRouter` в app.py (роуты
`/neuro`, `/ai`, API `/api/ai/*`, `/api/ai/folder*`, `/api/ai/chat/<id>/regenerate`).
`requirements.txt` теперь тянет `pypdf`. Тесты: `scratchpad/aitest.js`,
`aifeat*.js` (копирование/папки), `aiimg2.js` (фото), `batch2.js`/`batch3.js`
(стоп/перегенерация/поиск/пин/сайдбар/PDF/аватарки), `reason.js`
(размышления — таймер тикает, сворачивается на ответе, не копируется,
переживает reload), фейковый OpenRouter — `scratchpad/fakeor.py` (слово
`stopme` в тексте — отвечает медленно, чтобы успеть нажать «Стоп» в
тесте; при `reasoning` в запросе сперва шлёт несколько `delta.reasoning`).
Не доделано (если захочет): выбор модели прямо со страницы (сейчас только
через вкладки /neuro), редактирование своей реплики.

## Ограничения, заданные хозяином (соблюдать)

- Себастьян: гости из сети могут болтать, но НЕ управлять домашними
  устройствами. Модель — только та, что уже в памяти видеокарты; новую не
  поднимать (видеопамять занята).
- Страница серверов /servers — публичная: без локальных IP, без публичного
  адреса VPS, без адресов NetBird.
- Пароль корзины дропа хранится хэшем (sha256), не открытым текстом.

## Незакрытое (зависит от хозяина, не от кода)

- `SEBASTIAN_OLLAMA=http://<ubuntu-vm>:11434` на сервере — иначе чат
  Себастьяна не работает.
- `BACKUP_TOKEN` — для внешнего домашнего бэкапера.
