# vitazgio.ru — память проекта

Личный сайт Виталия (VITAZGIO). Один файл `app.py` (~15 тыс. строк) на Flask,
HTML/CSS/JS живут строками прямо в нём. Деплой: пуш в ветку `claude/**` →
GitHub Action «Claude auto-merge» → main → «Deploy» (домашний раннер по SSH
через NetBird на VPS в Амстердаме, `docker compose up -d --build web`).

Ветка разработки: `claude/project-overview-2mnq1j`.

## Как проверять (важно)

- Питон: `python3 -c "import ast; ast.parse(open('app.py').read())"`.
- Встроенный JS: `scratchpad/jscheck.py` — вытаскивает скрипты со всех
  страниц и гоняет `node --check`. **Обязательно** после правок шаблонов.
- Ловушка: `\n` внутри питоновской строки `"""..."""` становится настоящим
  переносом и рвёт JS. В шаблонах писать `\\n`. Дважды из-за этого падал дроп.
- Живая проверка: Playwright + Chromium
  `/opt/pw-browsers/chromium-1194/chrome-linux/chrome`,
  `NODE_PATH=/opt/node22/lib/node_modules`. Локальный запуск —
  `scratchpad/run.sh` (пароль кабинета `testpass`).

## Что сейчас в работе / решено

### Нейронки (кабинет → /neuro) — обёртка над двумя чатами
Одна карточка «Нейронки» в кабинете (акцент #7b6bff). Внутри — верхние
вкладки как в браузере: **DeepSeek** (сине-фиолетовая) и **Claude**
(оранжевая), у каждой своя тема шапки. Технически `/neuro` — тонкая
обёртка: два `<iframe>` на готовые `/ai` и `/claude`, ленивая загрузка
второй вкладки, выбор запоминается в localStorage. Чтобы дети встраивались,
у `/ai` и `/claude` выставлен `g.frameable=True` (X-Frame-Options SAMEORIGIN),
а их кнопка «назад» прячется в iframe через `html.embed .back{display:none}`
(детект `window.top!==window.self`). Отдельных карточек Claude/Нейросеть в
кабинете больше нет — только «Нейронки».

### Вкладка Claude (кабинет → /claude)
Готова как ЗАГОТОВКА, залита (коммит 3a20c01). Разговор с консольным
помощником через сайт: браузер → WebSocket `/ws/claude` → SSH (paramiko) →
tmux → команда. Тот же канал, что у консоли кабинета. Вкладки = сессии tmux
(`vg-1`, `vg-2`…), переживают закрытый браузер. Пускает пароль кабинета +
суточный пароль консоли. В коде НЕТ ничего специфичного для Claude —
запускает то, что в `CLAUDE_BIN`, так что туда встанет любой консольный агент.
Пока `CLAUDE_HOST` не задан в .env — страница висит безвредной заглушкой.
Настройка: `CLAUDE_HOST` (машина из NetBird с SSH), `CLAUDE_DIR`, `CLAUDE_BIN`.
Не доделано: автоподхват после «отцепиться», прикрепление фото, вход по ключу.

### Страница «Нейронки» /neuro + /ai — чаты через OpenRouter — СДЕЛАНО
DeepSeek у OpenRouter в 2026 сняли с бесплатных моделей целиком, поэтому
перешли на другие. `/neuro` — обёртка с тремя вкладками сверху, каждая
показывает `/ai?m=<модель>` в своём iframe и красится в свой цвет:
**MiniMax** (`minimax/minimax-m3:free`, малиново-фиолетовый, multimodal —
умеет фото), **NVIDIA** (`nvidia/nemotron-3-ultra-550b-a55b:free`, зелёный),
**Claude** (оранжевый, как раньше). Модель у каждой вкладки зашита в самой
странице (`/neuro`), в `.env` она не нужна — только `OPENROUTER_KEY`.
Если модель вкладки ответила ошибкой (сняли/переименовали/упёрлись в
лимит), сервер сам перебирает список живых бесплатных (раз в 15 мин
подтягивает каталог `/api/v1/models`, берёт всё с ценой 0).
Функционал чата на /ai:
- Список прошлых чатов слева, **папки** (создать/переименовать/удалить —
  удаление папки не трогает чаты, просто выкладывает их обратно),
  **переименование чата** (карандаш на строке), **перенос между папками**
  (иконка-папка на строке → меню). Всё на том же файле `data/aichat.json`.
- На каждом сообщении (и своём, и ответе) — **кнопка «Копировать»**,
  всплывает при наведении, копирует исходный текст в буфер.
- Ответ потоком (SSE) с живой печатью + markdown (жирный, код, ссылки).
- Фото: браузер ужимает картинку, сервер шлёт vision-модели (для
  MiniMax уже сама умеет) и хранит в `data/aichat_img/`.
- Реплика юзера сохраняется СРАЗУ: лимит исчерпан — написанное не пропадёт.
Настройка на сервере (.env): только `OPENROUTER_KEY` обязателен.
`OPENROUTER_MODEL`/`OPENROUTER_VISION_MODEL`/`OPENROUTER_URL` — опционально.
Код: блок `# Нейросеть: чат с DeepSeek через OpenRouter` в app.py (роуты
`/neuro`, `/ai`, API `/api/ai/*` и `/api/ai/folder*`). Тесты:
`scratchpad/aitest.js`, `aifeat*.js` (копирование/папки), фейковый
OpenRouter — `scratchpad/fakeor.py`.
Не доделано (если захочет): выбор модели прямо со страницы (сейчас только
через вкладки /neuro), поиск по чатам, редактирование своей реплики.

## Ограничения, заданные хозяином (соблюдать)

- Себастьян: гости из сети могут болтать, но НЕ управлять домашними
  устройствами. Модель — только та, что уже в памяти видеокарты; новую не
  поднимать (видеопамять занята).
- Страница серверов /servers — публичная: без локальных IP, без публичного
  адреса VPS, без адресов NetBird.
- Пароль корзины дропа хранится хэшем (sha256), не открытым текстом.

## Незакрытое (зависит от хозяина, не от кода)

- `SEBASTIAN_OLLAMA=http://<ubuntu-vm>:11434` на сервере — иначе чат
  Себастьяна не работает.
- `BACKUP_TOKEN` — для внешнего домашнего бэкапера.
