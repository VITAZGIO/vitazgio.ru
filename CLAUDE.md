# vitazgio.ru — память проекта

Личный сайт Виталия (VITAZGIO). Один файл `app.py` (~20 тыс. строк) на Flask,
HTML/CSS/JS живут строками прямо в нём (~75% файла — тройные кавычки с
шаблонами). Деплой: пуш в ветку `claude/**` → GitHub Action «Claude auto-merge»
→ main → «Deploy» (домашний раннер по SSH через NetBird на VPS в Амстердаме,
`docker compose up -d --build web`).

**Подробная хроника решений и переделок (кто что чинил, что откатывали и
почему) — в `docs/history.md`.** Здесь только правила и текущее состояние.
**Правила совместной работы с ИИ (модель, эффорт, разбивка по инструментам,
как экономить лимиты) — в `docs/workflow.md`.** **План разреза `app.py` на
шаблоны + blueprints — в `docs/codex-refactor-plan.md`.**

## Как проверять (важно)

- Питон: `python3 -c "import ast; ast.parse(open('app.py').read())"`.
- Встроенный JS: `scratchpad/jscheck.py` — вытаскивает скрипты со всех
  страниц (включая `/vg-player.js` и `/player/pop` как отдельные пункты) и
  гоняет `node --check`. **Обязательно** после правок шаблонов.
- Ловушка: `\n` внутри питоновской строки `"""..."""` становится настоящим
  переносом и рвёт JS. В шаблонах писать `\\n`. Дважды из-за этого падал дроп.
- Ловушка: локальную переменную-обработчик Escape нельзя звать `esc` — так
  зовётся глобальный html-экранировщик; конфликт даёт TDZ
  «Cannot access esc before initialization» и тихо ломает диалог.
- Живая проверка: Playwright + Chromium
  `/opt/pw-browsers/chromium-1194/chrome-linux/chrome`,
  `NODE_PATH=/opt/node22/lib/node_modules`. Локальный запуск —
  `scratchpad/run.sh` (пароль кабинета `testpass`).

## Скорость: что уже сделано (не откатывать)

Замеряли — сервер отдаёт страницу за 2-3 мс, то есть бэкенд ни при чём,
переписывать движок незачем. Тормозил объём.

- **gzip на ответах** (`compress_response`, after_request). Уровень 6.
  **Что обходим и почему** (ломать нельзя):
  — `text/event-stream` и генераторы (`is_streamed` без `direct_passthrough`)
    — SSE-чат нейронки, сжатие копило бы буфер и живая печать превратилась
    бы в один рывок в конце;
  — `send_file` с Range: у файлов `is_streamed` ТОЖЕ True, различаем по
    `direct_passthrough` + проверке типа (audio/*, video/*) + `GZIP_FILE_MAX`;
  — не 200 (206 Partial, 304 Not Modified), уже сжатое, мелочь до 1 КБ.
- **Кэш статики**: `/static/*` → сутки (Flask сам ставит `no-cache`, поэтому
  именно перезаписываем, `setdefault` молчал бы).
- **xterm и guacamole — по требованию** (`window.vendorReady`), тянутся
  `openTerminal`/`openRdp` при первом открытии, кэшируются в `done[]`.
  Итог по кабинету: **533 КБ → 49 КБ** по сети.
- Страницу `/claude` намеренно не трогали: там терминал и есть смысл
  страницы, `defer` и так не блокирует отрисовку.

## Что сейчас работает (текущее состояние)

### Вкладка Claude (кабинет → /claude)
Готова как ЗАГОТОВКА (коммит 3a20c01). Браузер → WebSocket `/ws/claude` →
SSH (paramiko) → tmux → команда. Тот же канал, что у консоли кабинета.
Вкладки = сессии tmux (`vg-1`, `vg-2`…), переживают закрытый браузер.
Пускает пароль кабинета + суточный пароль консоли. В коде НЕТ ничего
специфичного для Claude — запускает то, что в `CLAUDE_BIN`, туда встанет
любой консольный агент. Пока `CLAUDE_HOST` не задан в .env — страница
висит безвредной заглушкой. Настройка: `CLAUDE_HOST`, `CLAUDE_DIR`,
`CLAUDE_BIN`. Не доделано: автоподхват после «отцепиться», прикрепление
фото, вход по ключу.

### Музыка /music — избранная папка (звезда)
Любую папку можно пометить **звездой** (кнопка на плитке, только у
хозяина); избранная одна на всю фонотеку (новая гасит старую, чистится в
`music_folder_patch_api` при `fav:true`). Что даёт: (1) `/music` при
первом открытии сразу заходит в избранную папку, а не в пустой корень;
(2) `/api/player/tracks` и мини-плеер кабинета играют **только** её
содержимое с подпапками. Нет избранной — вся фонотека, как раньше. Флаг
`fav` живёт в `music_folders[id]`, отдаётся в `/api/music`
(`fav_folder` + `fav` у каждой папки). Тест — `scratchpad` (звезда,
переключение, фильтрация player/tracks и мини-плеера). Корневая крошка —
«Вся музыка».

### Дроп — совпадение имён при загрузке (как в проводнике)
Файл с уже занятым в этой папке именем спрашивает карточкой (`askConflict`,
в стиле сайта): **Сохранить оба** (дописывает `(2)`, `freeName`),
**Заменить** (старое в корзину через `/api/drop/op` op=delete, новое
встаёт под тем же именем), **Пропустить**. Галочка «Применить ко всем»
запоминает выбор на остаток пачки (`forAll`). Проверка — по `items`
текущей папки; занятые имена копим в `taken`, чтобы файлы одной пачки не
занимали имя повторно. Тест — `scratchpad/dropconflict.js`.

### Дроп → MUSIK — создание папок и загрузка музыки
Папка MUSIK в дропе не хранит своё, а показывает саму фонотеку (папки с
id `mf_`, треки с `mt_`). При `parent == "musik"` или `parent` c
префиксом `mf_` создаётся НАСТОЯЩАЯ папка фонотеки (`music_folders`,
ответ отдаёт `id` уже с `mf_`), с проверкой глубины `MUSIC_MAX_DEPTH`. Так
папка, заведённая в дропе, — та же, что видит плеер и `/music`; загрузка
роутится в фонотеку (`_drop_music_take` по `mf_`-родителю).

### DIY /diy — один вид листания (Кладка)
Единственная и безусловная раскладка — Кладка (JS-masonry, не CSS
column-count). Переключателя видов больше нет (было пять — Сетка/Барабан/
Кладка/Веер/Соты, хозяин попросил оставить только Кладку). Тест —
`scratchpad/diy.js` (переключателя нет, класс сетки всегда `m-mosaic`,
кладка не ломается при смене полки).

### Плеер (виджет + `/player/pop`) — текущее устройство
Один на весь сайт: `<audio>` живёт в модуле, состояние едет между
страницами через `localStorage`, между вкладками синхронизируется через
`BroadcastChannel("vgplayer")`.

**Как это работает сейчас (не путать с историей переделок в history.md):**
- В памяти живёт **намерение** (`wantPlay`), а не факт `!audio.paused` —
  иначе быстрое листание вкладок обрывает музыку (трек грузится, автоподхват
  ждёт опроса других вкладок — если уйти со страницы в эту щель, факт был бы
  `false`). Снимается намерение только настоящей паузой (человек нажал, трек
  кончился); служебные паузы помечены `quiet` и намерение не трогают.
- Перед автовключением `resume()` спрашивает через `BroadcastChannel`
  («ping»/«pong», ~220мс), не играет ли уже кто-то — без этого открытие
  сайта во второй вкладке обрывало музыку в первой. Ответ не блокирует
  постановку трека (тот встаёт сразу), только решение «включать звук»
  (`goIfAllowed`/`userActed`).
- **Кнопки на сайте** (⧉ в кабинете `#pl-pop`, «Вынести в окно» на
  `/music`) зовут `VGP.popOut()` → открывают **независимое окно**
  `/player/pop` (свой звук, не гаснет при навигации по сайту). Эстафета:
  `popOut()` ставит `audio.pause()` на сайте (запоминает секунду через
  `save()`), сразу перезаписывает `playing:true` в `localStorage` для
  нового окна; асинхронное событие `pause` на время передачи (`quiet`,
  сброс через 300мс) не зовёт `save()`, иначе затёрло бы `playing` обратно.
  Обе кнопки, если `VGP.popOut` вдруг нет (не догрузился новый движок),
  падают на запасной путь `window.open("/player/pop", …)`.
- **Внутри** `/player/pop` кнопка ⧉ (`floatOnTop`) даёт хромлесс-плавашку
  поверх всех окон, переживающую переходы (само окно никуда не идёт):
  Chrome/Edge — Document Picture-in-Picture (живой виджет); Firefox — его
  нет вовсе, там видео-PiP «как у ютубе» (плеер рисуется на `<canvas>`,
  `captureStream()` → немой `<video>` → `requestPictureInPicture()`,
  управление через `mediaSession`). У видео-PiP кликабельного списка
  треков нет и быть не может (внутри одни пиксели) — железное ограничение.
  Класс `vgp-top` = «уже поверх всех», прячет кнопку повторно.
- В окне `/player/pop` кнопка «свернуть» скрыта (`.vgp.vgp-pip
  [data-fold]`), `setFolded` — пустышка: развернуть свёрнутый кружок там
  нечем (обработчик перетаскивания выходит сразу на `vgp-pip`).
- Список треков в окне (`drawRows`) двухуровневый: если папок больше
  одной — сперва папки (иконка + название + счётчик, склонение
  трек/трека/треков), тычок заходит внутрь, «‹ Все папки» назад.
  Счётчик — `.n span`, НЕ первый `span` в строке (первый — иконка
  `.fico`). Автоподсветка играющего трека включена только когда реально
  показаны треки (есть `[data-i]`), иначе дёргалась бы в обзоре папок.
- Выбор папки — из ПОЛНОГО дерева фонотеки, не только из загруженной
  очереди: `/api/player/tracks` отдаёт `folders` (всё дерево) + `fav`,
  принимает `?folder=<id>` (с подпапками) либо `?folder=__all__` (вся
  музыка вопреки избранному).
- Громкость — ползунок `data-volbar` в теле виджета, мьют по клику на
  значок, помнит прошлый уровень (`api.volume()`).
- `/vg-player.js` отдаётся `private, no-cache` + ETag по md5 текста +
  `make_conditional` — после деплоя браузер обязан перепроверить версию
  (иначе кнопки на свежей странице зовут метод, которого ещё нет в
  закэшированном старом движке).
- Свои карточки подтверждений везде, где раньше был бы системный диалог,
  — паттерн, действующий и на `/ai` (см. ниже).

Тесты: `scratchpad/popfolders.js`, `scratchpad/popfold.js`,
`scratchpad/player.js`, `scratchpad/flip.js`, `scratchpad/popbtn.js`,
`scratchpad/lag.js`.

### Страница «Нейронки» /neuro + /ai — чаты через OpenRouter
Одна карточка «Нейронки» в кабинете (нейтральный акцент #9aa3c9).
`/neuro` — три вкладки, каждая грузит `/ai?m=<модель>` в iframe и красится
в свой цвет: **MiniMax** (`minimax/minimax-m3:free`, розовый, умеет фото),
**NVIDIA** (`nvidia/nemotron-3-ultra-550b-a55b:free`, зелёный), **Claude**
(оранжевый). Модель зашита в `/neuro`, в `.env` нужен только
`OPENROUTER_KEY`. Если модель вкладки ответила ошибкой, сервер сам
перебирает список живых бесплатных (каталог `/api/v1/models`, цена 0,
обновляется раз в 15 мин).

Функционал `/ai`: папки чатов (создать/переименовать/удалить —
удаление папки не трогает чаты), переименование чата, перенос между
папками, закрепление (булавка → секция «Закреплённые»), поиск по
заголовкам. Сайдбар 317px, сворачивается (кнопка внутри сайдбара,
разворачивается плавающей кнопкой у края;
`localStorage.aiSidebarCollapsed`). Подтверждения/ввод — свои карточки
(`uiConfirm`/`uiPrompt`/`uiToast`), не системные. На сообщениях —
«Копировать», на ответах — «В блокнот» (`/api/notebook/entry`) и на
последнем ответе «Заново» (`POST /api/ai/chat/<id>/regenerate`). Кнопка
**Стоп** — `AbortController`, сервер ловит обрыв как `GeneratorExit` в
`finally` у `_ai_run_stream` и досохраняет частичный ответ. Автозаголовок
(`_ai_smart_title`) долетает первым кадром SSE (`{"title": ...}`).

Аватарка бота — буквы и цвет по модели, которая **реально ответила** на
конкретное сообщение (`m.model` в `data/aichat.json`), не по текущей
вкладке — иначе переключение MiniMax/NVIDIA/Claude красило старые
сообщения не в те цвета (`avaFor(model)` + `avColorFor`, инлайн-стиль на
`.av`). Ответ потоком (SSE) с markdown. Фото: до `AI_IMG_COUNT_MAX`=6 за
раз, выбор файлов ИЛИ вставка из буфера (Ctrl+V, `clipboardData.items`),
хранение — `umsg["imgs"]` (список id), совместимость со старым одиночным
`image`/`img` через `_ai_msg_imgs`. PDF — отдельная кнопка-скрепка, до
8 МБ, текст через `pypdf` (`_ai_pdf_extract`, до 6000 симв.),
подкладывается в контекст на КАЖДОМ следующем ходе разговора, не только
в момент прикрепления. Размышления (reasoning) у MiniMax и
NVIDIA/Nemotron (`_ai_wants_reasoning`) — отдельное поле
`delta.reasoning`/`delta.reasoning_content`, таймер «Думает… N с», на
первом куске ответа блок сворачивается («Думал»), сохраняется вместе с
сообщением (`reasoning`/`reasoning_secs`). Кнопка «Копировать» reasoning
в буфер не тянет — только `out.dataset.raw` (куда пишутся исключительно
куски `delta.content`). Реплика юзера сохраняется СРАЗУ (лимит исчерпан —
написанное не пропадёт). Цвета везде через
`color-mix(in srgb, var(--ac) N%, transparent)`, не хардкод.

Настройка (.env): только `OPENROUTER_KEY` обязателен.
`OPENROUTER_MODEL`/`OPENROUTER_VISION_MODEL`/`OPENROUTER_URL` — опционально.
Код: блок `# Нейросеть: чат с DeepSeek через OpenRouter` в app.py (роуты
`/neuro`, `/ai`, API `/api/ai/*`, `/api/ai/folder*`,
`/api/ai/chat/<id>/regenerate`). `requirements.txt` тянет `pypdf`. Тесты:
`scratchpad/aitest.js`, `aifeat*.js`, `aiimg2.js`/`aiimg3.js`,
`batch2.js`/`batch3.js`, `reason.js`, фейковый OpenRouter —
`scratchpad/fakeor.py` (слово `stopme` — медленный ответ для теста
«Стоп»; при `reasoning` в запросе сперва шлёт несколько
`delta.reasoning`). Не доделано (если захочет): выбор модели прямо со
страницы, редактирование своей реплики.

## Ограничения, заданные хозяином (соблюдать)

- Себастьян: гости из сети могут болтать, но НЕ управлять домашними
  устройствами. Модель — только та, что уже в памяти видеокарты; новую не
  поднимать (видеопамять занята).
- Страница серверов /servers — публичная: без локальных IP, без публичного
  адреса VPS, без адресов NetBird.
- Пароль корзины дропа хранится хэшем (sha256), не открытым текстом.

## Незакрытое (зависит от хозяина, не от кода)

- `SEBASTIAN_OLLAMA=http://<ubuntu-vm>:11434` на сервере — иначе чат
  Себастьяна не работает.
- `BACKUP_TOKEN` — для внешнего домашнего бэкапера.
